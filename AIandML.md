## Types of machines learning
### Supervised learning
- Data is already labeled
- Can predict/classify future outcomes based on past data
- Requires that at least an input and output variable be given to the model for it to be trained

### Unsupervised learning
- Employ unlabeled data to discover patterns from the data on their own, identify hidden features
- Some examples of unsupervised learning include k-means clustering, hierarchical clustering, association, and anomaly detection

### Semi-supervised
- Uses a combination of a small amount of labeled data and a large amount of unlabeled data to train models

### Reinforcement learning
- Train an agent to complete a task within an uncertain environment.
- Agent receives observations and a reward from the environment and sends actions to the environment. The reward measures how successful action is with respect to completing the task goal

## Data Preprocessing
Data preprocessing is a key aspect of data preparation. It refers to any processing applied to raw data to ready it for further analysis or processing tasks

- Handling **missing** values
- Remove **duplicates** or identify them
- Detecting and removing **outliers**
- **Normalization** of the data
    - scales the data, usually between 0 and 1
    - standardize the data, to have a mean of 0 and a standard deviation of 1
- **Resampling** the data
    - rebalance the data when there's an imbalance in classes, helps to reduce biases
    - random under-sampling to reduce the quantity of the majority class
    - random over-sampling to increase the quantity of the minority class
    - SMOTE over-sampling to increase the quantity of the minority class
